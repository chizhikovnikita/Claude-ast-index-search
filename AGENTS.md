# Правила проекта

Прочитай [agent.md](agent.md): это памятка по архитектуре, проверкам и работе
с данным форком.

Оригинальный `defendend/Claude-ast-index-search` используется только для чтения.
Ничего не отправляй туда: ни коммиты, ни ветки, ни теги, в том числе через
прямой URL. Единственное место публикации этого проекта —
`chizhikovnikita/Claude-ast-index-search`.

Перед началом работы прочитай [CLAUDE.md](CLAUDE.md) и применимые правила
из [.claude/rules/](.claude/rules/). Соблюдай их при работе с этим проектом.

Если присутствует `.agents/skills/software-development/SKILL.md`, для
`$software-development` используй эту локальную копию. В Codex она доступна
как `$ast-index:software-development`. Локальный навык и `.sds` не входят в
поставку форка: в свежем клоне их отсутствие не блокирует работу; следуй
`agent.md`, `CLAUDE.md` и правилам проекта.
